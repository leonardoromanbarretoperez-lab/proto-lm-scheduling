de forma independiente?

Tres alternativas para resolver la variabilidad de configuración entre semanas en el panel de revisión de vehículos.

Problema: con 4 semanas seleccionadas, todas comparten la misma configuración

Variante B
Toggle + tabs por semana
Un switch "Configurar por semana" activa tabs independientes dentro de cada card de vehículo. Por defecto, una sola config para todas las semanas.
Flujo simple por defecto
Flexible cuando se necesita
Más clicks para llegar a la variabilidad

Variante D
Columnas comparativas
Cada semana es una columna dentro del card de vehículo. Ciclo, ETA y días de cada semana visibles y editables al mismo tiempo.
Comparación inmediata entre semanas
Cero clicks extra para editar
Densidad visual alta con 4 semanas

Variante E
Copiar + diff visual
La primera semana es la referencia. Las demás arrancan como "igual a Sem anterior" y se activan con "Personalizar". Los campos que difieren se resaltan en azul.
Ideal cuando las semanas son casi iguales
Diff visual muestra cambios de un vistazo
Flujo más largo si todas las semanas varían
